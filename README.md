## Исследуемые архитектуры

В рамках работы сравниваются три класса нейросетевых архитектур:

- **MLP (многослойный перцептрон)** — базовая архитектура, не учитывающая временную структуру данных. Входной вектор формируется путём развёртки временного окна фиксированной длины. Выступает в качестве бенчмарка для оценки сложности задачи.

- **RNN (рекурррентные нейронные сети)** — реализованы на основе архитектуры LSTM (долгая краткосрочная память), которая решает проблему исчезающего градиента и способна моделировать долгосрочные зависимости в последовательностях.

- **CNN (свёрточные нейронные сети)** — одномерные свёрточные сети, извлекающие локальные временные паттерны с возможностью параллельной обработки входной последовательности.

## Методология эксперимента

### Предобработка данных

Для каждого датасета выполняется следующий набор операций:

1. **Загрузка и первичный анализ** — проверка структуры данных, типов признаков, наличия временной метки.

2. **Обработка пропусков** — линейная интерполяция с последующим заполнением вперёд и назад (ffill + bfill) для устранения оставшихся пропусков.

3. **Проверка стационарности** — расширенный тест Дики-Фуллера (ADF) для каждого признака. Ряд считается стационарным, если более половины признаков имеют p-value < 0.05.

4. **Оценка тренда** — вычисление корреляции Пирсона между временной осью и рядом значений. При |corr| > 0.7 фиксируется наличие выраженного тренда, при |corr| > 0.3 — слабый тренд.

5. **Оценка сезонности** — анализ автокорреляционной функции (ACF) на лаге 24. Наличие значимой корреляции свидетельствует о суточной сезонности.

6. **Нормализация** — масштабирование значений в диапазон [0, 1] с использованием MinMaxScaler. Параметры масштабирования вычисляются только на обучающей выборке для предотвращения утечки данных.

7. **Формирование временных окон** — размер окна составляет 24 шага (история), горизонт прогнозирования — 1 шаг вперёд.

### Разделение выборки

- Обучающая выборка — 60% данных
- Валидационная выборка — 20% данных (используется для ранней остановки)
- Тестовая выборка — 20% данных (используется для итоговой оценки)

### Гиперпараметры обучения

Для обеспечения сопоставимости результатов все три архитектуры обучаются с идентичными гиперпараметрами:

| Параметр | Значение |
|----------|----------|
| Размер временного окна | 24 |
| Горизонт прогнозирования | 1 |
| Количество эпох | 100 |
| Размер пакета (batch size) | 64 |
| Скорость обучения (learning rate) | 0.001 |
| Количество скрытых слоёв | 2 |
| Количество нейронов / фильтров | 64 |
| Dropout | 0.2 |
| Функция потерь | MSE |
| Оптимизатор | Adam |
| Ранняя остановка | patience = 10 |

### Воспроизводимость

Для обеспечения воспроизводимости результатов фиксируется начальное состояние генераторов случайных чисел (seed = 42) для библиотек NumPy и TensorFlow. Ранняя остановка восстанавливает лучшие веса модели.

## Оценка качества

Сравнение моделей производится по следующим метрикам:

- **MAE (Mean Absolute Error)** — средняя абсолютная ошибка, интерпретируемая в единицах измерения целевой переменной. Показывает величину типичного отклонения прогноза от фактического значения.

- **RMSE (Root Mean Square Error)** — среднеквадратичная ошибка, более чувствительная к крупным отклонениям. Штрафует модели, допускающие единичные сильные выбросы.

- **Время обучения** — фиксируется в секундах для оценки вычислительной эффективности каждой архитектуры.

## Результаты

Для каждой модели на каждом датасете фиксируются:

- Значения MAE и RMSE на тестовой выборке
- Время обучения в секундах
- Количество обучаемых параметров
- График прогнозов в сопоставлении с реальными значениями (по первому признаку)
- График динамики функции потерь и MAE в процессе обучения

Итоговые результаты сводятся в таблицы сравнения, позволяющие выявить зависимость эффективности архитектур от свойств временных рядов.

## Установка и запуск

1. Клонируйте репозиторий:

```bash
git clone https://github.com/mobyzova/nn_architectures_comparison.git
cd nn_architectures_comparison
```

2. Создайте виртуальное окружение (рекомендуется):

```bash
python -m venv venv
```

3. Активируйте виртуальное окружение:

- Windows:

```bash
venv\Scripts\activate
```

- macOS / Linux:

```bash
source venv/bin/activate
```

4. Установите зависимости:

```bash
pip install -r requirements.txt
```

5. Поместите файлы датасетов (ETTm1.csv, exchange_rate.csv, weather.csv, electricity.csv) в папку data, расположенную в корне проекта.

6. Запустите модуль предобработки данных:

```bash
python module1.py
```

Этот модуль выполняет загрузку датасетов из папки data, интерполяцию пропусков, нормализацию, проверку стационарности, формирование временных окон и сохраняет обработанные данные в папку processed, а графики — в папку plots.
После выполнения в папках processed и plots появятся обработанные данные, JSON-логи с характеристиками рядов и графики разведочного анализа.

7. Запустите модуль обучения и сравнения моделей:

```bash
python module2.py
```

Этот модуль загружает обработанные данные, создаёт и обучает три нейросетевые архитектуры (MLP, RNN на основе LSTM, CNN) на каждом датасете, вычисляет метрики качества (MAE, RMSE), фиксирует время обучения и сохраняет результаты в папку results. Модели сохраняются в папку models, а их архитектуры — в папку model_summaries. После выполнения в папках results, models, model_summaries, plots появятся результаты эксперимента: CSV-таблицы с метриками, сохранённые модели, файлы с архитектурами сетей, графики прогнозов и динамики обучения.
